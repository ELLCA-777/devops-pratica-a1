# Prática A1 — DevOps

Projeto desenvolvido para aplicar conceitos de DevOps por meio de um sistema simples de controle de estoque.

A aplicação permite cadastrar produtos, validar informações, adicionar itens ao inventário e consultar o valor total armazenado.

Além da aplicação, o projeto utiliza Git, organização por branches, testes automatizados, Pull Requests e integração contínua com GitHub Actions.

## Tecnologias utilizadas

- Node.js 22 ou superior
- JavaScript
- Git e GitHub
- GitHub Actions
- Node.js Test Runner

## Funcionalidades

- Cadastro de produtos.
- Validação de nomes, quantidades e preços.
- Controle de produtos em estoque.
- Cálculo do valor total do inventário.
- Testes unitários e de integração.
- Processo automatizado de build.
